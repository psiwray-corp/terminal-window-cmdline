# 08 — POSIX PTY

**Phase:** platform · **Depends on:** 07 · **Blocks:** 10

## Goal

A real PTY backend on Linux and macOS using pure FFM. The child sees a tty,
job control works, resize uses `TIOCSWINSZ`, and `vim`/`less`/`top` behave as
interactive programs.

`tty/unix.rs`, node-pty `pty.cc`, and POSIX `openpty`/`posix_spawn` docs. Do not
read sibling sections. Expected output: FFM bindings, `PosixPtySession`,

## Steps

1. FFM-link libc: `posix_openpt`, `grantpt`, `unlockpt`, `ptsname_r` (Linux) /
   `TIOCPTYGNAME` (macOS), `open`, `close`, `read`, `write`, `ioctl`,
   `tcgetattr`, `tcsetattr`, `posix_spawn*`, `waitpid`, `kill`.
2. Create the PTY; set `IUTF8`; set initial `winsize`.
3. `posix_spawn` with `POSIX_SPAWN_SETSID`, `SETSIGDEF`, `SETSIGMASK`. On
   Linux, close inherited descriptors and add slave `open`/`dup2(0/1/2)` and
   close actions. On macOS, add only the slave `open`/`dup2(0/1/2)` actions; a
   child `/bin/sh` wrapper closes the inherited PTY descriptors and reopens
   the slave after `SETSID`.
4. Reader thread: blocking `read(master)` into `ByteRing`; handle EOF/EIO.
5. Writer thread: blocking `write(master)` from the queue.
6. Watcher: `waitpid(pid, ...)`; publish `ProcessExit(exitCode, signal)`.
7. Resize: `ioctl(master/slave, TIOCSWINSZ, winsize)`; kernel sends
   `SIGWINCH`.
8. Signals: `SIGHUP`/`SIGTERM` to the child process group; `SIGINT` is normally
   generated by the tty from `0x03`, but `requestInterrupt` may send it.
9. macOS spike: verify `isatty(0)`, `tcgetpgrp`, `ps -o tpgid`, `stty size`,
   job control, and `SIGWINCH`. If controlling terminal is absent, stop and
   report; do not add a native helper without a user decision.
10. Tests: `sh -c 'tty; stty size; printf hello'`, resize, exit, signal,
    fd-leak checks.

## Pitfalls

- `posix_spawn` must set `SETSID`; otherwise job control fails.
- Open the slave in the child after `SETSID`, then `dup2` it; duplicating an
  already-open slave does not establish a controlling terminal.
- Darwin's `posix_spawn` close actions have produced `EBADF` for this
  descriptor setup; keep close actions out of the macOS path and let the child
  shell manage the inherited descriptors after `SETSID`.
- `ioctl` and `open` are variadic; mark the variadic argument with
  `Linker.Option.firstVariadicArg`.
- `ptsname` is not thread-safe; use `ptsname_r` on Linux and locked `ptsname` on macOS.
- `read(master)` returns `EIO` on child exit; treat as EOF, not a crash.
- `waitpid` must target the child pid; do not reap unrelated children.
- macOS `TIOCSWINSZ`/`TIOCPTYGNAME` constants differ from Linux.
- Do not block the owner thread in `read`/`write`; use the dedicated threads.
